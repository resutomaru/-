# Слабые ключи — реестр R5-класса по ВСЕМ категориям (2026-06-11)

Мандат Алексея (11.06): «нужно чтобы все категории были ограничены от такого риска».
Риск R5-класса: **бакет-полочка, смешивающая товары с существенно разными ценами** → медиана-каша →
ложные «ниже рынка» в Ф6 (ось E17/E19, RR-03/RR-04).

**Принцип:** ключ существует ТОЛЬКО если он определяет ценовой класс товара. Не определяет → `null`
(«не уверен — молчим»; лот остаётся в базе, но не судится по цене и не становится находкой).

## Правило на будущее (вписано в процесс NEW-2)

Любое расширение словарей/ключей сверяется с этим реестром: новая форма ключа обязана отвечать
на вопрос «одинаково ли стоят товары внутри такого бакета?» — иначе null или явная запись сюда
как осознанное огрубление.

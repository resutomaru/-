# Разметка золотого набора condition

`expected` — это **ИСТИНА** (как лот ДОЛЖЕН классифицироваться), НЕ предсказание текущей функции.
Реальность измеряет харнесс в `golden_set.sql` сам — он не верит на слово.

## Метки

**dead** (hard-drop, исключается из медианы) — явный сигнал неработоспособности:
- на запчасти / на з/ч / донор / под восстановление / для разбирающихся
- не включается / не запускается / не стартует
- не работает (наст.) **И** не работал / работала / работало (прош. — E3)
- неисправен / **не исправен** (с пробелом — E2)
- **нерабочая / нерабочее / нерабочую** про сам предмет, в т.ч. без соседнего существительного (E4)
- нет изображения / не выводит изображение / артефачит / артефакты как дефект
- сгорел / дохлый / не видит / отвал(а)

**working** — явный сигнал работоспособности:
- полностью рабочая / идеально работает / 100% рабочая
- на гарантии / гарантия до / чек есть / сохранён / пломбы / проверен
- «после майнинга» → **working** (это износ-штраф в БАЛЛЕ, не метка)

**unknown** (проходит гейт со штрафом) — нет функционального сигнала ИЛИ:
- не тестировал / не проверял / не могу проверить / не знаю

## Опасная ось (`danger=true`)

Истина = dead, но текст соблазняет классификатор сказать working/unknown — это E1/E18.
Нулевая терпимость: `dead → working` обязан быть **0**.
`dead → unknown` — тоже утечка (мёртвое проходит гейт со штрафом), считаем отдельным счётчиком.

## Ловушки гарда (метку НЕ менять)

- «не работает **вентилятор / подсветка / разъём / порт**» у рабочей карты → working/unknown (E6-fan).
- НО: «**не работает [карта]**, вентилятор крутится» → **dead** (E5). Карта мертва, вентилятор «в стороне».
- Эти два кейса в прямой **тензии** под чистым regex-гардом: закрыть E5, не сломав E6-fan, скорее всего
  потребует LLM-добивки (Фаза 4) или гарда по близости к предмету. Зафиксировано как находка аудита.
- «по цене нерабочей», «артефакты отсутствуют» при явном «полностью рабочая» → **working**
  (E6: ценовой хедж / отрицание дефекта).

## Наполнение реальными строками

- `source='real'`, `expected` ставит человек по правилам выше, `danger=true` для мёртвых-с-соблазном.
- Цель (§7): 300–500 строк, баланс working/dead/unknown, перевес на пограничные.
- Источник: экспорт из `lots` (или прямой read-доступ к БД), затем ручная разметка.

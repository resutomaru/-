🤖 Перекуп-помощник — как устроена вся машина

Автономный «завод-монолит» сам 24/7 находит и проверяет выгодные б/у комплектующие. У каждого клиента — отдельный личный помощник со своими фильтрами. Связь между ними одна: помощник читает готовый склад. Сделано под массовый запуск «под ключ», не только под одного человека.

Завод — общий, автономный Личный помощник — у каждого свой Настройки — Google-таблицы Рост — на потом
🔌 Главный принцип: завод и помощник почти не пересекаются. Одна дверь — «склад находок», в одну сторону (помощник только читает). Завод про клиентов не знает ничего и крутится сам. Поэтому его легко тестировать, масштабировать на сколько угодно клиентов и продавать его данные отдельно.

🏆 Чем обходим конкурента

  • ✓ Завод-монолит, автономный: его данные — отдельный товар на продажу (у него завод и клиент смешаны).
  • ✓ Кнопка «купил?» — петля, которая кормит журнал, автонастройку и данные (у него такой петли нет).
  • ✓ Светофор доверия против развода — главная боль перекупа (у него нет вообще).
  • ✓ Запасной сборщик + справочник моделей, проверенный на реальных лотах.
  • ✓ Карточка-решение с кнопкой + веб-кабинет + журнал реального навара.
  • ✓ Журнал-бухгалтерия заменяет ручной эксель: занести сделку — один тап, бот сам всё подставил (у него учёта прибыли нет вообще).
  • ✓ Честный режим цены — не показываем выдуманную выгоду на фейковых ценах.
  • ✓ Защита от потопа, два слоя анти-спама, флаг уверенности цены — продумано против сбоев.
  • ✓ Слой предохранителей + живой риск-реестр + датчики-метрики — у конкурента о надёжности ни слова.

🛡️ Предохранители — что держит, когда что-то ломается

Чем сложнее продукт, тем больше дыр — это закон. Поэтому не латаем по списку, а строим систему, которая ловит дыры сама, до того как они стрельнут. Спина — три принципа:

🤫 Тихо лучше, чем ложноНеуверен — молчим или помечаем, не пушим. Один плохой пуш (развод/дохлое) дороже ста хороших.
🧯 Падать безопасноСломалось — откат к последнему хорошему или к осторожному режиму, никогда к мусору.
🧱 Изоляция взрываЗавод и помощник раздельны — баг в одном не валит другое.

Опасные места и их предохранители

Добыча
🔴 Источник упал / забанен / сменил формат / съел лимит.
🔧 Запасной сборщик + датчик «нет лотов N минут» + проверка формата (кривое в карантин) + жёсткий потолок запросов.
Стоимость
🔴 Разгон запросов/LLM → внезапный счёт.
🔧 Потолок бюджета + автостоп при превышении + LLM только на спорное + кэш ответов.
Опознание
🔴 Неверная модель / мусор в категории.
🔧 «Не уверен — не находка» + флаг уверенности + golden-набор + превью-дифф перед каждым изменением словаря.
Цена
🔴 Ложная «выгода» (фейк-цена / тонкая выборка / выброс / протухло).
🔧 Тест-режим до реальных цен + минимум K лотов + отсев выбросов + «скидка >70% — не зелёное» + флаг устаревания.
Состояние
🔴 Дохлое помечено рабочим.
🔧 Сомнение → «непонятно», не «рабочее»; golden с нулевой терпимостью dead→working; LLM на спорное.
Доверие
🔴 Светофор пропустил развод (ложный зелёный).
🔧 Перекос в осторожность (сомнение → жёлтый); красное не прячем, показываем с предупреждением; дообучение на «купил→развод».
Помощник
🔴 Спам/потоп (баг / кривой конфиг / вывал склада).
🔧 Жёсткий лимит пушей в час/день на клиента; тихие часы; на старте только свежее; перебор → дайджест; пауза-клиента.
Мультитенант
🔴 Чужие данные ушли не тому клиенту.
🔧 client_id на всём + проверка на каждом сообщении; chat_id подтверждаем при подключении; тест «второй клиент видит другое».
Конфиг
🔴 Кривая таблица (цена 0 / всё подряд).
🔧 Проверка диапазонов на синке; сломалась → работаем по последним хорошим настройкам + сигнал клиенту.
Деньги
🔴 Журнал считает навар неверно → рушится доверие к цифрам.
🔧 Показываем разбор (закупка + расходы → навар), всё редактируемо; продажу не угадываем; «оценка» и «факт» — разной меткой.
Данные
🔴 Утечка личного при продаже данных.
🔧 Наружу только обезличенные агрегаты (человека не вычислить); личные сделки не продаём; согласие в условиях.
Релизы
🔴 Правка молча ломает другое; старый сниппет вернулся.
🔧 golden-набор на каждый мозг (без прохождения не катим); превью-дифф; git = единственная правда; раскатка ступенями.
Инфра
🔴 Крутится на ПК, не 24/7 → дыры в медиане.
🔧 Завод на облаке всегда-вкл + датчик аптайма + автоперезапуск.
Секреты
🔴 Токен в URL/коде; потеря данных.
🔧 Секрет-хранилище + ротация; БД с бэкапами + регулярные выгрузки.

Как не проморгать дыру вовремя

📋 Живой реестр рисковКаждая дыра записана со статусом и своим предохранителем. Растёт продукт — растёт реестр, ничего не теряется.
📈 Датчики-метрикиТочность находок, ложные «ниже рынка», dead→working, пропущенные разводы, спам-рейт, расход денег. Тревога на отклонении — до жалобы клиента.
🌑 Теневой режимВсё новое сначала молча на реальных данных; смотрим датчики; потом включаем клиентам.
Черновик-схема на согласование. Скажи, что добавить/убрать/переставить — поправлю, и только потом идём в детали.
